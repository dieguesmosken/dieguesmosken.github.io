Recadin Beta fechado

Quem assiste manda um Pix e o recado aparece no OBS da live: lido por voz de IA, com som, vídeo ou a música pedida. O valor cai direto na conta Mercado Pago do streamer, e a comissão da plataforma é retida automaticamente. Inclui metas, personalização do visual e fila de moderação para aprovar, pular ou recusar cada recado.

Arquitetura: serverless com custo zero de infraestrutura no plano gratuito da Cloudflare.

  • Cloudflare Workers + Hono servem o front-end em React + Vite, a API REST e os webhooks num único Worker.
  • Mercado Pago Orders API gera o Pix com application_fee para split de receita; webhooks validados por HMAC-SHA256 e tokens OAuth criptografados com AES-GCM.
  • Durable Objects + WebSocket Hibernation mantêm uma fila isolada por streamer e o overlay conectado em tempo real.
  • D1, Queues e R2 guardam dados, geram o áudio de voz de forma assíncrona e entregam os arquivos ao OBS sem custo de saída.
  • Cloudflare Workers
  • Hono
  • React
  • Mercado Pago Orders API
  • Pix
  • WebSockets
  • D1 · R2 · Queues
